# UASA Sains Tingkatan 2 2026 — GitHub Pages

## Kandungan
- `index.html`: worksheet live responsif untuk telefon, komputer dan iPhone.
- `UASA_SAINS_T2_2026.pdf`: kertas soalan asal, dikekalkan tanpa mengubah kandungan.

## Cara terbitkan menggunakan GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu (contoh `uasa-sains-t2-2026`).
2. Muat naik `index.html` dan `UASA_SAINS_T2_2026.pdf` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, kemudian tekan **Save**.
6. Tunggu GitHub memaparkan URL Pages. Kongsi URL itu kepada murid.

## Cara murid menjawab
1. Buka URL menggunakan Safari (iPhone), Chrome, Edge atau pelayar lain.
2. Isi nama dan kelas.
3. Rujuk kertas soalan asal, kemudian isi jawapan dalam ruang worksheet.
4. Tekan **Simpan / Cetak jawapan sebagai PDF**.
5. Pilih **Save as PDF** pada komputer. Pada iPhone: Share → Print → besarkan pratonton dengan dua jari → Share → Save to Files.
6. Hantar PDF jawapan kepada guru melalui saluran yang ditetapkan.

## Nota
- Kertas soalan asal dipaparkan sebagai PDF supaya rajah dan kandungan asal tidak diubah.
- Jawapan tidak dihantar secara automatik kepada guru dan tidak disimpan ke pangkalan data. Murid perlu menghantar PDF yang dijana.
- Cetakan PDF mengandungi maklumat murid dan jawapan worksheet; kertas soalan asal dibuka/dikekalkan sebagai PDF berasingan.
- Jika perlu kutip jawapan secara automatik, perlu tambah backend atau integrasi borang yang mempunyai storan.
